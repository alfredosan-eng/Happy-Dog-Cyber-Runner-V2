> Run • Collect • Survive • Repeat

A colorful arcade runner evolved from the original **Happy Dog Cyber Runner**.

## 🎮 V2 Features

- 🐕 Choose from **4 playable dogs** with distinct visual designs.
- 🌈 Bright blue, red, yellow and green arcade palette.
- 🏙️ **Parallax city background** with low and tall buildings moving at different speeds.
- 🚗 Smaller cars, buses, motorcycles and street sweepers with jump-friendly 2D collision boxes.
- 🦴 Regular and golden bones.
- 🛡 Shield, 🧲 Magnet and 🩷 Extra Life power-ups.
- 🔥 Bone combos and score multipliers.
- 📈 Levels increase every 20 collected bones, with increasing speed.
- 🎵 **Good Enough Main Theme** background music in a continuous loop.
- 🔊 In-game **SOUND ON/OFF** control.
- 💀 Game Over screen with bones collected, final score and best score.
- ▶️ **NEXT GAME** replay flow.
- 🌐 No external libraries required.

## 🎧 Sound

The background music can be turned on or off from the start screen or during the game using the **SOUND ON/OFF** control or the `M` key. The selected track loops continuously while sound is enabled.

## ▶️ Play

Open `index.html` in a modern browser, or publish the repository with GitHub Pages.

### Controls

| Action | Control |
|---|---|
| Jump | `SPACE` / `↑` |
| Pause | `P` |
| Choose dog | `A` / `D` or `↑` / `↓` on the menu |
| Choose difficulty | `←` / `→` on the menu |
| Sound on/off | `M` |
| Start / Next Game | `ENTER` / `SPACE` |
